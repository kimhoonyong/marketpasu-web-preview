가격압력 참고 표시 — 봉 아래의 빨간 짧은 막대: 매수압력 추정(고가권 종가) / 파란 짧은 막대: 매도압력 추정(저가권 종가). 봉의 상승·하락과 별개입니다. 실제 매수주도/매도주도 체결량을 확인한 결과는 아닙니다. OHLC는 기본 숨김입니다. 차트 위의 「OHLC 보기」를 누르면 시가·고가·종가·저가가 차트 바깥 정보줄에 표시되고, 「OHLC 숨기기」를 누르면 사라집니다. 진짜 체결 우위 판단은 키움 실시간 0B 자료를 거래 중 수집하고, 누락 여부를 확인해야 합니다.

키움 API가 제공하는 실제 과거 기록만 표시합니다. 일봉 최대 1,200개, 분봉 최대 8,000개(기준일 이전 최대 21일 범위)를 요청하지만 제공량은 종목·거래소·연속조회 응답에 따라 달라집니다. 분봉은 조회일보다 이전 거래일을 포함할 수 있습니다. 화면에서는 최신 구간부터 확대해 보여주고 「전체 기간」으로 전체 자료를 확인합니다. 구버전 PC 연결기는 과거 확장조회를 지원하지 않습니다.

일봉 거래대금은 키움 제공치(백만원 단위를 원으로 환산)이며, 분봉 거래대금은 ka10080 미제공으로 종가×거래량 추정치만 표시합니다. 일봉 평균체결단가(거래대금÷거래량)는 제공된 일봉 거래대금이 있을 때만 산출하며, 분봉에는 (고가+저가+종가)÷3 참고가격만 표시합니다. 저가권 종가·윗꼬리 등 매도압력 가능성은 가격 패턴이지 실제 매도 체결량 증거가 아닙니다.

■ 상승봉 ■ 하락봉 · 이동평균선은 종가 기준 5·10·20·60·120·240봉이며, 20선·240선은 굵게 표시합니다. 필요한 봉 수가 부족한 선은 그리지 않습니다. 마우스 휠·손가락 벌리기로 확대/축소하고 차트를 드래그해 이동하세요.

고급 분석 · 뉴스 전후 분봉·일봉 CSV 직접 비교 (선택사항)

뉴스가 나오기 2시간 전부터 이후 30분까지 가격·거래량·거래대금과 체결 방향을 분석합니다. 이 기능은 현재 내 PC·휴대폰 브라우저에서만 실행됩니다.

뉴스 시간은 Google 뉴스 RSS 게시시각이므로 최초 보도시각이 아닐 수 있습니다. 결과는 매집·세력·시세조종의 확정 판정이 아닙니다.

뉴스를 선택하면 제목에 언급된 종목 후보를 제안합니다. 후보는 종목 확인이 아니며, 분석 전에 직접 검증해야 합니다.

저장된 분봉은 아직 불러오지 않았습니다. 저장 기능은 기기별로 작동하며 외부 서버에는 전송하지 않습니다.

뉴스 이전 몇 주간의 일봉 · 가격대 방어 분석

선택된 기사와 같은 종목의 최근 최대 60거래일을 분석합니다. 뉴스 당일과 이후 일봉은 포함하지 않습니다. 과거 가격대에 반복적으로 접근한 뒤 다시 반등했는지 확인합니다.

일봉 자료가 없습니다. 키움 일봉 CSV를 선택하면 뉴스 이전 수급 흔적을 검토할 수 있습니다.

일봉은 어느 투자자가 실제 주식을 매수했는지 보여주지 않습니다. 가격대 방어가 보이더라도 사전 정보 이용이나 시세조종으로 단정하지 않습니다. 기준 가격대는 이전 구간에서 설정하고 이후 구간에서 재검증합니다.

일봉 + 분봉 공동 관측 결과

같은 뉴스·같은 종목을 대상으로 일봉과 분봉을 각각 분석하면 결과를 나란히 비교합니다. 뉴스 최초 보도시각이 미확인된 경우에는 판단을 보류합니다.

종목·증시·실적 관련 기사만 선별합니다.

출처: Google 뉴스 공개 RSS · 투자 관련 제목 중심 선별 · 동일 사건의 관련 원문은 모두 보존. 특정 종목이 검색 주제에 들어 있어도 제목이 무관하면 제외합니다. 이 선별은 시가총액·뉴스 진위·세력 매집 판단이 아닙니다.

표시할 기사가 없습니다.

종목명 검색어를 지우거나 관심 키워드를 다시 선택하세요. 투자 관련도가 낮은 기사와 블로그 글은 제외됩니다.

현재 제공 범위 · 운영 안내

Google 뉴스 RSS는 뉴스 검색 중계 출처입니다. 검색 주제와 무관한 블로그·시승기·일반 생활기사는 제목·발행처 기준으로 제외하고, 추적 중인 주요 기업·시장 관련 제목을 선별합니다. 소형주 전체를 나쁜 종목으로 단정하는 필터는 아닙니다. 동일 사건 추정 묶음은 원문을 보존하나 실제 기사 내용·재탕 의도를 확정하지 않습니다. 모든 원문을 보려면 「원문 전체 보기」를 누르세요.

이 화면은 공개 기사 제목·발행처·발행시각·원문 링크만 제공합니다. 뉴스 원문은 언론사 사이트에서 읽습니다. 각 기사에 대한 사실 확인, 제목 변경·재노출 판정, 투자 추천을 제공하지 않습니다.

뉴스 파일은 GitHub Pages에서 제공되며 주기적 공개 RSS 수집 작업으로 갱신하도록 설계했습니다. 갱신 실패 시 과거 목록이 남을 수 있습니다. 반드시 ‘기사 기준일’을 확인하세요. 새 소식 버튼은 기존 파일을 다시 읽는 기능으로, 즉시 외부 뉴스를 새로 수집하지는 않습니다.

「기사 관측 이력」의 처음·최근 날짜는 마켓파수가 RSS에서 확인한 날입니다. 기사 최초 보도일, 실제 재발행, 언론사 원문 삭제 시점이 아닙니다. 관측 기록은 최근 30일 범위에서만 유지합니다.

읽음 표시는 기사 원문 링크를 누르거나 「읽음 표시」 버튼을 누르면 기록됩니다. 새로 추가된 기사 표시는 이 기기에서 이전에 받아본 목록과 비교한 결과이며, 발행 시점의 속보를 뜻하지 않습니다.

시세 데이터 자동 연결을 위해서는 증권사 시세 API의 이용자 인증 및 제공 조건을 별도로 확인해야 합니다. API 키를 공개 GitHub 웹페이지에 저장하지 않으며, 현재 시세 자동수집은 활성화하지 않았습니다.

관심 키워드와 읽음 표시는 현재 브라우저에만 저장되며 다른 PC·휴대폰과 동기화되지 않습니다. 가입·결제·Firebase 운영 데이터 조회·AI API·텔레그램 발송은 이 화면에서 하지 않습니다. 기존 인증 시험은 상단 링크로 계속 이용할 수 있습니다.
